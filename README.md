# Elektronik lernen – Lernplattform (HTL)

Öffentliche Lernwebseite für Elektronik, Mess- und Regelungstechnik, gebaut mit [Astro Starlight](https://starlight.astro.build).
Keine Anmeldung, keine Cookies, kein Tracking.

## Lokal ansehen

```powershell
npm install      # nur beim ersten Mal
npm run dev      # Vorschau auf http://localhost:4321
```

Die Suche funktioniert nur in der fertig gebauten Version:

```powershell
npm run build
npm run preview
```

Die fertige Webseite liegt nach `npm run build` im Ordner `dist/` und kann auf jeden einfachen Webspace hochgeladen werden.

Regeln und Aufbau des Projekts: siehe [CLAUDE.md](CLAUDE.md).
