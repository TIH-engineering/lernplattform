## Das solltest du können

<Kasten typ="lernziele" titel="Am Ende kannst du …">

- die Resonanzbedingung angeben und die Resonanzfrequenz berechnen
- Reihen- und Parallelschwingkreis bei Resonanz beschreiben (Impedanz, Strom, Spannungs- bzw. Stromüberhöhung)
- Güte, Bandbreite und Grenzfrequenzen berechnen und an der Resonanzkurve ablesen
- die Resonanzfrequenz eines realen Parallelschwingkreises herleiten und angeben, wann keine Resonanz auftritt
- Grenzfrequenz, Betrag und Phase von RC-Tief- und Hochpässen berechnen und ein Bode-Diagramm skizzieren

</Kasten>

## Wichtige Zusammenhänge

| Größe | Formel |
| --- | --- |
| Resonanzbedingung | $X_\mathrm{L} = X_\mathrm{C}$ bzw. $\operatorname{Im}(\underline{Z}) = 0$ |
| Thomsonsche Schwingungsformel | $f_0 = \dfrac{1}{2\pi\sqrt{LC}}$ |
| Kennwiderstand | $Z_0 = \sqrt{L/C}$ ($= X_\mathrm{L} = X_\mathrm{C}$ bei Resonanz) |
| Güte Reihenkreis | $Q = \dfrac{Z_0}{R}$, Spannungsüberhöhung $U_\mathrm{L} = U_\mathrm{C} = Q \cdot U$ |
| Güte Parallelkreis (R parallel) | $Q = \dfrac{R}{Z_0}$, Stromüberhöhung $I_\mathrm{L} = I_\mathrm{C} = Q \cdot I$ |
| Bandbreite | $B = f_\mathrm{o} - f_\mathrm{u} = \dfrac{f_0}{Q}$ |
| RC-Tief-/Hochpass | $f_\mathrm{g} = \dfrac{1}{2\pi R C}$, bei $f_\mathrm{g}$: $\dfrac{U_\mathrm{a}}{U_\mathrm{e}} = \dfrac{1}{\sqrt 2}$ (−3 dB), Phase ∓45° |
