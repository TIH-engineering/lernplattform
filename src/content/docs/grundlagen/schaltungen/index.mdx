## Das solltest du können

- Knoten- und Maschenregel formulieren und anwenden
- Ersatzwiderstände von Reihen-, Parallel- und gemischten Schaltungen berechnen
- Spannungs- und Stromteilerregel anwenden – und die Probe machen
- den Einfluss einer Last auf einen Spannungsteiler beurteilen
- Vorwiderstände (z. B. für LEDs) und Messbereichserweiterungen berechnen

## Wichtige Zusammenhänge

| Reihenschaltung | Parallelschaltung |
| --- | --- |
| gleicher Strom durch alle Widerstände | gleiche Spannung an allen Widerständen |
| $R_\mathrm{ges} = R_1 + R_2 + \ldots$ | $\dfrac{1}{R_\mathrm{ges}} = \dfrac{1}{R_1} + \dfrac{1}{R_2} + \ldots$ |
| $U = U_1 + U_2 + \ldots$ (Maschenregel) | $I = I_1 + I_2 + \ldots$ (Knotenregel) |
| Spannungsteiler: $\dfrac{U_1}{U} = \dfrac{R_1}{R_\mathrm{ges}}$ | Stromteiler (2 Zweige): $I_1 = I \cdot \dfrac{R_2}{R_1 + R_2}$ |

Für zwei parallele Widerstände: $R_\mathrm{ges} = \dfrac{R_1 \cdot R_2}{R_1 + R_2}$ – das Ergebnis ist **immer kleiner** als der kleinste Einzelwiderstand.
