## Das solltest du können

- Feldlinienbilder zeichnen (homogen/inhomogen) und die Stelle größter Feldstärke angeben
- Feldstärke, Flussdichte und Kapazität berechnen: Plattenkondensator, Wickelkondensator, Koaxialkabel, Kugel
- Reihen-, Parallel- und gemischte Kondensatorschaltungen berechnen (Ladungen und Teilspannungen)
- die im Kondensator gespeicherte Energie berechnen
- das Laden und Entladen über einen Widerstand mit der Zeitkonstante $\tau = R \cdot C$ beschreiben

## Wichtige Zusammenhänge

| Größe | Formel |
| --- | --- |
| Feldstärke (homogen) | $E = \dfrac{U}{d}$ in V/m |
| Flussdichte | $D = \dfrac{Q}{A} = \varepsilon_0 \varepsilon_\mathrm{r} E$ |
| Kapazität | $C = \dfrac{Q}{U}$ · Plattenkondensator: $C = \dfrac{\varepsilon_0 \varepsilon_\mathrm{r} A}{d}$ |
| Koaxialleitung | $C = \dfrac{2\pi \varepsilon_0 \varepsilon_\mathrm{r} l}{\ln(D/d)}$ |
| Kugel gegen Erde (weit entfernt) | $C = 4\pi \varepsilon_0 \varepsilon_\mathrm{r} r$ |
| Parallelschaltung | $C = C_1 + C_2 + \ldots$ (gleiche Spannung) |
| Reihenschaltung | $\dfrac{1}{C} = \dfrac{1}{C_1} + \dfrac{1}{C_2} + \ldots$ (gleiche Ladung) |
| Energie | $W = \tfrac12 C U^2$ |
| Laden über $R$ | $u_\mathrm{C}(t) = U_\mathrm{q}\,(1 - \mathrm{e}^{-t/\tau})$, $i(t) = \dfrac{U_\mathrm{q}}{R}\,\mathrm{e}^{-t/\tau}$, $\tau = R C$ |

Elektrische Feldkonstante: $\varepsilon_0 = 8{,}85 \cdot 10^{-12}\,\mathrm{F/m}$
